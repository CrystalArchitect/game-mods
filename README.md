# Game Mods

Personal game mods and local compatibility fixes by aurous37-lang.

## Valheim

[**Knee-Slapper’s Abilities and Gear**](valheim/KneeSlapperAbilities/README.md) includes freezing wooden arrows, infinite wooden arrows, a gathering kit, unlimited stamina and tool durability, increased carrying capacity, double jump, and no fall damage.

Includes local compatibility patch source for Plant Everything, Recycle N Reclaim, and Comfy Quick Slots on Valheim 1.0.7, plus integration with Better Archery, InfinityTools, and PlecakDlaCweli.

Game assemblies, third-party mod DLLs, decompiled reference code, and personal saves are not included. Install the original dependencies separately, then apply the local patches using the instructions below.
